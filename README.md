# 🚀 FLEX-TWEAKS v1.0
**Ultimate Windows 10/11 Performance & Privacy Optimizer**

FLEX-TWEAKS is a powerful batch script designed to strip away Windows bloatware, disable telemetry, and optimize system settings for maximum gaming performance and privacy.

## 🛠️ Key Features:
* **Deep Clean:** Removes Windows Temp files and system junk.
* **Privacy First:** Disables Telemetry, Advertising ID, and Data Collection.
* **Gaming Boost:** Optimizes GPU settings and disables unnecessary background services.
* **Bloatware Remover:** Cleans up pre-installed UWP apps.
* **Context Menu Fix:** Restores the classic Windows 10 context menu on Windows 11.

## ⚠️ How to Use:
1. Download `FLEX-TWEAKS v1.0.bat`.
2. **Right-click** and select **Run as Administrator** (Required).
3. Follow the on-screen instructions.
